# niwa-ds

## Data Analyst / Analytics Design

Python・SQL（BigQuery）を中心に、  
**分析設計 → データ理解 → 判断・施策提案**までを一貫して行うデータアナリストです。

単なる集計や可視化にとどまらず、  
「何を判断するための分析か」を起点に  
分析手法・粒度・アウトプットを設計することを重視しています。

また、分析結果の信頼性を担保するために、  
**再現性のある環境構築（Docker / DevContainer）** や  
**分析コードの構造化・テスト**にも取り組んでいます。

---

## Core Skills / 強み

- 課題に応じた **分析設計・手法選択**
- SQL / Python / 統計を役割分担して用いる分析プロセス設計
- 分析結果を **判断・ネクストアクションに接続するアウトプット**
- 再現性・可読性を意識した分析環境・コード設計

## 技術スキル

### 言語
- **Python**：pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels
- **SQL（BigQuery）**：CTE, Window Functions, 正規表現, データ整形

### 分析・統計
- EDA（探索的データ分析）
- Feature Engineering（特徴量設計・加工）
- 統計的検定（t検定、χ²検定 など）
- ロジスティック回帰（解釈重視）
- **統計検定2級 取得済み**

### 分析基盤・開発環境
- 依存管理：pyproject.toml
- 開発環境：DevContainer（VS Code + Docker）
- 実行環境：Docker / Docker Compose
- コード構成：`src/` 配下に分析用関数・ユーティリティを整理
- テスト：pytest による関数単位のテスト

### BI・ログ分析
- Looker Studio：ダッシュボード設計・再構築
- GA4：ユーザー行動分析 / BigQuery Export 運用
